# ThemeSystem 开发指南

> 主题系统，支持深色/浅色两套配色方案

---

## 1. 配色方案

### 浅色（天蓝）配色
```
窗体背景:    #EBF8FF (235,248,255)
工具栏背景:  #EBF5FF (235,245,255)
边框:        #ADD1ED (173,209,237)
主文字:      #143C64 (20,60,100)
次要文字:    #5A82AA (90,130,170)
按钮主色:    #42A5F5 (66,165,245)
按钮深色:    #1E88E5 (30,136,229)
```

### 深色（VS风格）配色
```
窗体背景:    #1E1E1E (30,30,30)
工具栏背景:  #252526 (37,37,38)
边框:        #3E3E42 (62,62,66)
主文字:      #F1F1F1 (241,241,241)
次要文字:    #C8C8C8 (200,200,200)
```

---

## 2. 主题切换机制

- `ThemeMode` 枚举：`Dark` / `Light`
- 全局状态：`CsvSettings.ThemeMode`（0=深色, 1=浅色）
- 主窗体 `Form1.ApplyTheme()` 遍历所有子控件和面板调用 `ApplyTheme(isDark)`

---

## 3. 各组件 ApplyTheme 方法

| 组件 | 方法 | 说明 |
|------|------|------|
| `Form1` | `ApplyTheme()` | 主窗体 + 工具栏 + 所有面板 |
| `FileBrowserPanel` | `ApplyTheme(bool isDark)` | 设置 `_isDark` → `SetThemeColors(isDark)` |
| `CsvReaderForm` | `ApplyTheme()` | 文件树 + 标签页 + 搜索栏 |
| `LargeFileViewer` | `ApplyTheme()` | 文件列表 + 标签页 |
| `TableBrowserControl` | 构造函数中处理 | 使用 `_isDark` 相关配色字段 |

---

## 4. 新增控件时的主题规则

1. 在类的构造函数或 `ApplyTheme()` 中处理主题切换
2. 使用 `_isDark` 字段判断当前主题
3. 所有颜色必须从配色方案中选取，不要硬编码新颜色
4. 新增控件必须同步更新 `ApplyTheme()` 方法

---

## 5. 修改禁区

- **❌ 不要新增配色方案颜色**（除非同时更新深色和浅色两套）
- **❌ 不要在单个控件中硬编码颜色值**（应使用类级别的配色字段）
- **❌ 主题切换时不要遗漏任何子控件**
