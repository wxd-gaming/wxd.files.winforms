# 核心功能需求
###
在当前项目采用按钮打开WPF窗体，winforms窗体兼容wpf形式打开，创建文件要求是utf-8编码
### 超大文件加载（核心对标 EmEditor）
支持10GB 及以上文本日志文件秒级打开
采用流式读取 / 分块加载，不将整个文件加载到内存
打开 10GB 文件内存占用 ≤ 500MB，无卡死、无崩溃
支持常见日志格式：.log / .txt / .out / .gz（压缩日志直接预览）
### 日志查看功能
支持滚动浏览，滚动流畅无延迟
支持跳转到指定行 / 指定时间点（按日志时间戳跳转）
支持实时刷新（监控正在写入的日志文件）
支持行号显示、换行控制、编码自动识别（UTF-8/GBK）
支持高亮显示：错误日志（ERROR/FAIL）、异常栈（Exception）自定义关键词高亮
### 日志查询 / 检索（高频核心）
全文搜索：超大文件内毫秒级检索关键词
支持精准搜索、模糊搜索、多行搜索
支持正则表达式搜索（定位复杂日志）
支持过滤显示：只显示包含关键词的行（隐藏无关内容）
搜索结果分页展示、快速跳转、支持导出搜索结果
支持多条件组合检索：时间范围 + 关键词 + 日志级别
### 辅助效率功能
日志导出：导出检索结果 / 选中行 / 指定范围日志
日志对比：对比两个日志文件差异
书签功能：标记关键日志行，快速跳转
快捷键支持：模仿 EmEditor 常用快捷键，降低学习成本
日志统计：统计关键词出现次数、错误数量
# 非功能需求
### 性能要求
10GB 文件打开时间 ≤ 3 秒
关键词搜索响应时间 ≤ 1 秒
滚动、翻页无卡顿，CPU 占用低
### 兼容性
支持 Windows 10/11（优先），可选支持 macOS/Linux
支持所有标准文本日志格式
支持大文件断点续读
### 易用性
界面简洁，模仿 EmEditor 操作逻辑
无需复杂配置，开箱即用
支持中文界面
### 稳定性
长时间打开大文件不崩溃
检索、归档操作无数据丢失
异常退出后可恢复上次打开的文件
# 界面布局建议（贴近 EmEditor）
顶部：文件打开、在线连接、搜索框、归档按钮
左侧：行号区、书签区
中间：日志内容主显示区
底部：搜索结果面板、状态条（文件大小 / 当前行 / 内存占用）
# 可选扩展功能
多文件同时打开、多标签页切换
